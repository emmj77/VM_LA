La mise à jour

Une seule brique décide : config/engine/update.sh. Cette page ne lit jamais git elle-même — elle demanderait une seconde vérité. L'update refuse si l'arbre est sale ou si un tour tourne, pose le tag la-avant-update, puis redémarre le pont en dernier, détaché : la réponse est déjà écrite quand la porte se referme.
